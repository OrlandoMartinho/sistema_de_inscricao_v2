# 🎓 Sistema de Inscrição - IP30SET

Este é um sistema web simples desenvolvido para gerenciar as **inscrições** no Instituto Médio Politécnico 30 de Setembro (IP30SET). O sistema possui uma interface de administração, páginas de eventos, contatos e gerenciamento de usuários.

## 🚀 Funcionalidades

- Simulação de login para administrador
- Painel administrativo com páginas de gestão
- Visualização de eventos e informações institucionais
- Páginas públicas e privadas organizadas
- Estrutura modular com HTML, CSS e JavaScript puro

## 🔐 Acesso de Administração (Simulado)

Para entrar na área de administração, utilize as seguintes credenciais no formulário de login:

- **Usuário:** `admin`
- **Senha:** `12345`

> O sistema valida os dados com JavaScript puro. Nenhum backend foi implementado até o momento.

## 🛠 Tecnologias Utilizadas

## ⚙️ Como Executar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/OrlandoMartinho/sistema_de_inscricao_v2.git
   ```
2. Abra a pasta no VS Code ou outro editor.
3. Clique com o botão direito no arquivo `login.html` e escolha **"Abrir com Live Server"** (ou abra no navegador manualmente via `localhost` se estiver com servidor local ativo).
